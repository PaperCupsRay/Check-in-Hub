代理池 0

供「GitHub Actions · 浏览器过盾」通道使用。Cloudflare 对 GHA 机房 IP 常静默不签发 Turnstile 挑战（组件能渲染但永远等不到 token），换成住宅出口后实测 27s 即可拿到 token。
每行一个，支持 socks5://、socks4://、http://、https://，可带 user:pass@ 和 #备注；省略协议按 socks5 处理。
凭证差异（实测）：Chromium 不支持 SOCKS 用户名密码认证，SOCKS 代理的凭证会被自动剥掉（很多公开代理的 user:pass 只是摆设，剥掉照样能用）；HTTP/HTTPS 代理的 Basic 认证浏览器原生支持，凭证会保留。
安全提示：签到时会带渠道 Cookie / 访问令牌，运行前会逐个校验代理有没有解密 TLS（对比证书指纹）。做中间人的代理会被自动拒用——2026-09-11 实测一批公开「住宅 SOCKS5」全部在换证书，用了等于把凭证明文交给代理方。
检测出口：推荐 GitHub，验证真实 HTTPS、TLS 证书和出口 IP；Worker 仅测握手，结果不代表 GitHub 可用。检测不会向代理发送渠道凭证，HTTPS 通过也不保证目标站一定能过盾。
仅检测已保存且启用的代理；GitHub 任务完成后自动更新。
